# Order Service

Microsserviço responsável pelo gerenciamento de pedidos.

## Objetivo

Este serviço permite:

- Criar pedidos
- Listar pedidos
- Buscar pedidos por ID

O projeto foi desenvolvido para demonstrar conceitos de arquitetura de microsserviços, APIs REST e documentação técnica.


# Tecnologias Utilizadas

- Python
- Flask
- Docker

# Responsabilidade do Microsserviço

Este microsserviço possui responsabilidade única relacionada ao gerenciamento de pedidos,
seguindo os princípios de arquitetura de microsserviços.
